Slik handler kontoen
  • Fordeling. {{ policy.long_pct | int }} % langsiktig og {{ policy.short_pct | int }} % kortsiktig, ingen kontantdel. Inntil {{ policy.max_positions }} langsiktige aksjer, hver på minst {{ policy.min_position | nok }}, som i rådgiverens standardoppsett.
  • Langsiktig del. Ombalanseres første handelsdag hver måned: aksjer som fortsatt er blant de {{ rules.hold_rank }} beste, beholdes, resten selges, og de høyest rangerte den ikke eier, kjøpes til den har {{ policy.max_positions }}. Strengere krav for å komme inn enn for å bli holder handelen og kurtasjen nede.
  • Kortsiktig del. Kjøper rådgiverens hendelsessignaler (nytt tilbakekjøpsprogram, flere innsidere som kjøper), høyst {{ rules.max_new_short }} nye om dagen og så mange samtidig som pengene rekker, og selger hver etter {{ rules.short_hold }} handelsdager.
  • Åpningstider. Oslo Børs handler 09:00–16:25 og Nasdaq Stockholm 09:00–17:30, med egne helligdager. Beslutningene tas om kvelden og utføres til åpningskurs neste dag aksjen handles. En ordre som ikke er utført etter {{ rules.order_days }} handelsdager, faller bort.
  • Nordnets priser (Norge, kurtasjeklasse Mini, sjekket 4. oktober 2026): {{ (fees.courtage * 100) | num(2) }} % kurtasje, minst {{ fees.minimum | num(0) }} NOK per handel i nordiske aksjer. Svenske aksjer koster i tillegg {{ (fees.exchange * 100) | num(2) }} % i valutaveksling ved både kjøp og salg.
  • Utbytte godskrives på eksdagen; svensk utbytte etter {{ (fees.dividend_tax * 100) | int }} % kildeskatt. Ingen norsk skatt, som på en aksjesparekonto.
  • Ikke med: at en stor ordre kan flytte kursen, og forsinkelsen fra du ser et signal til du handler. Ordrene er små i forhold til omsetningen, siden rådgiveren bare velger aksjer med god likviditet.
